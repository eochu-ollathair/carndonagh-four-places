# Carndonagh: four recorded places near Donagh Cross

This small comma-separated file gives the recorded positions of Donagh Cross, Donagh Church, the Marigold Stone and St Patrick's Bed near Carndonagh, County Donegal. It is useful for putting the four records on one map instead of treating the famous cross as the whole story.

The positions come from [Discover Alone's two-page Carndonagh field sheet](https://discoveralone.com/assets/guide/carndonagh-field-sheet.html). That sheet has a position diagram, short explanations and links to each place's underlying record. The longer [Carndonagh guide](https://discoveralone.com/stories/one-place-tells-you-nothing-put-them-together) explains how the four places fit together.

Open [`places.csv`](places.csv) in a spreadsheet or map program using `latitude` and `longitude` as decimal degrees. The dots show recorded positions, **not** a walking route, entrance or permission to enter. Access to St Patrick's Bed is unconfirmed, and the stones noted in its record had already been removed before that survey. Check current access before visiting any site.

Prepared by Rickie Doherty for Discover Alone from its published Carndonagh field sheet. The four rows are deliberately small enough to inspect by hand.
